# bibliotecas-frontend

Frontend en Angular para registrar bibliotecas y ver los libros de cada una.

## Requisitos

- Node.js 22 o superior
- Backend corriendo en `http://localhost:8080`

## Ejecutar

```bash
npm install
npm start
```

Abrir <http://localhost:4200>

## Funcionalidades

- Formulario para registrar bibliotecas (nombre, dirección, ciudad).
- Tabla con los libros y su biblioteca, obtenidos de `GET /bibliotecas`.
